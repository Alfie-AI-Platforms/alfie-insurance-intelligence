# Alfie: Insurance Intelligence

Create the initial dashboard UI for “Alfie Insurance”, an AI-native workspace for insurance companies.

The design should feel like a modern enterprise AI workspace similar in overall interaction pattern to ChatGPT, Claude, or Harvey — not like a traditional insurance administration dashboard. Alfie is the intelligence and execution layer across the insurer’s existing systems.

Use a clean, premium, minimal enterprise interface with a persistent left sidebar, large central workspace, and contextual right sidebar.

Below suggested prompts, show Recent Activity with examples of Alfie completing work.

Show several previous Alfie conversations with their related insurance function.

IMPORTANT PRODUCT PRINCIPLES

- This is an AI workspace first, not a conventional dashboard.
- Alfie should be visually present throughout the experience.
- The user should be able to accomplish work through natural language.
- Do not create detailed claims, underwriting, policy, pricing, or finance workflows yet.
- The sidebar navigation should be functional and ready for those workflows to be built later.
- Keep the interface sophisticated, spacious, and enterprise-grade.
- Use realistic insurance terminology and sample data.
- Do not make it look like a consumer banking app.
- Do not add unnecessary charts or excessive dashboard widgets.
- The primary interaction should feel like opening an AI workspace and asking Alfie to understand, analyze, recommend, and execute insurance work.
